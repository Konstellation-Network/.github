# Trademark policy

The code in Konstellation's repositories is open source. **The Konstellation
name and logo are not.** The code licenses (Apache-2.0, MIT, CC BY 4.0,
CC BY-ND 4.0) give you rights to the code and text. They give you no rights to
the names and logos below. Apache-2.0 says this explicitly in section 6.

This policy lets anyone build on the code, while making sure that anything
called "Konstellation" really is Konstellation. For a blockchain, that is a
safety issue as much as a branding one: users must be able to tell the real
network from a copy.

## The marks

- the name **Konstellation**, alone or in names such as "Konstellation
  Network", "Konstellation Testnet" and "Konstellation Devnet"
- **KASH**, as the name of Konstellation's native token
- the Konstellation logo

Trademark registrations are being prepared. Until the legal entity that will
hold them is formed, the marks are held on behalf of the Konstellation Network
project.

## What you may do without asking

- **Refer to Konstellation truthfully.** For example: "a wallet that supports
  Konstellation", "deployed on Konstellation", "a Konstellation explorer", or
  writing about the project.
- **Redistribute official, unmodified releases** under their own name.
- **Use the name in the chain's own metadata**, such as wallet network lists
  and chain registries, for the official networks (chain IDs 5667, 56671 and
  56672).
- **Use the name and logo in articles, tutorials and talks** about
  Konstellation, provided you don't alter the logo and don't imply you are the
  project.

## What you may not do

- **Call a fork or modified version "Konstellation"**, or anything
  confusingly similar. A modified node, network, wallet or token must have its
  own name and logo. "Based on Konstellation" in its description is fine.
- **Imply that the project endorses, operates or partners with you** when it
  doesn't.
- **Use the marks for another network or another token.** That includes
  calling a token on another chain "KASH" in a way that suggests it is
  Konstellation's native token.
- **Register domains, social accounts, app names or package names** that
  contain the marks and could be mistaken for official ones.
- **Change the logo**, or use it as part of your own logo.

A network that runs this code must also use its **own EIP-155 chain ID**, not
5667, 56671 or 56672. Transactions signed for one chain with a given ID can be
replayed on any other chain with the same ID. The node software refuses to run
a non-Konstellation chain with those IDs.

## Asking for permission

To ask about a use not covered here, open an issue in this repository. We
answer requests in good faith, and approve most community and educational uses.

This policy may change. It is not legal advice, and it does not limit uses
that the law permits anyway, such as fair use.
